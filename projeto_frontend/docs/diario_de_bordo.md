# Diário de bordo — ARENA SPORTS

> Modelo para o grupo preencher conforme o trabalho real acontecer. Nenhuma data, reunião ou atividade foi preenchida de antemão.

## Como usar
1. Copie o bloco "Registro" abaixo a cada encontro ou dia de trabalho.
2. Preencha todos os campos, mesmo que seja para escrever "nenhuma".
3. Guarde este arquivo no repositório e faça commit a cada registro.
