# ARENA SPORTS — Projeto Front-End

**Portal esportivo acadêmico para reunir clubes, competições, jogos e classificações em um só lugar.**

## 1. Nome do projeto

**ARENA SPORTS**

O ARENA SPORTS é um portal esportivo desenvolvido como projeto acadêmico de Desenvolvimento Web (Front-End).

## 2. Objetivo do site

O objetivo do ARENA SPORTS é oferecer um ambiente digital organizado e intuitivo para acompanhar informações esportivas. O portal reúne conteúdos sobre clubes, competições, partidas e classificações, apresentando também a fonte e o horário de atualização dos dados.

Entre os recursos propostos e apresentados no projeto estão:

- Pesquisa de clubes, seleções e competições;
- Consulta de partidas, resultados e classificações;
- Acompanhamento de diferentes modalidades esportivas;
- Personalização da página inicial com times favoritos;
- Preferências de notificações;
- Alternância entre tema claro e escuro;
- Suporte a diferentes idiomas.

O projeto também permite aplicar conhecimentos de estruturação HTML, estilização CSS, programação JavaScript, organização de arquivos e integração com recursos externos.

**Observação:** o site é um projeto acadêmico e demonstrativo. Os formulários apresentam mensagens de confirmação no próprio navegador, mas não enviam nem armazenam informações em um servidor.

## 4. Tecnologias utilizadas

- **HTML5:** estruturação semântica e organização das páginas.
- **CSS3:** identidade visual, layouts, responsividade e estilização.
- **JavaScript:** interações do menu, validação e feedback de formulários, contador de caracteres e filtro da galeria.
- **TheSportsDB:** consulta de dados esportivos no portal incorporado.
- **Wikipédia:** consulta de informações históricas e títulos.
- **Git:** controle de versão.
- **GitHub:** hospedagem do repositório e colaboração.
- **Visual Studio Code:** ambiente de edição e desenvolvimento.

O projeto utiliza HTML, CSS e JavaScript puro, sem frameworks front-end.
